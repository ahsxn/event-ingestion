Event Ingestion Pipeline

An event-driven AWS application built with Go, Terraform, Laravel and React.

Live Demo View Source

The live AWS demo may occasionally be offline from 10:00 pm to 8:00 am while the environment is sleeping to reduce costs.

Architecture

Producer → API Gateway → Go Lambda → Kinesis → Go ECS Worker → DynamoDB

Events are accepted through API Gateway, validated by a Go Lambda function and written to Kinesis. A Go worker running on ECS processes the stream and updates aggregate metrics in DynamoDB.

A Laravel and React dashboard reads those metrics and provides a simple interface for demonstrating the pipeline.

Stack

Go AWS Lambda API Gateway Kinesis ECS EC2 DynamoDB Terraform Docker Laravel React GitHub Actions
